**BUSINESS NEED:**

This module allows administrators to simplify the shopfloor user interface by hiding package-related actions during the reception scenario.

It is specifically designed for warehouses that do not utilize packages during their receptions, preventing warehouse operators from accidentally creating unwanted packages or cluttering the UI with unused buttons.

**APPROACH:**

You can configure on the picking type level if you want to use packages or not.

**USEFUL INFORMATION:**

It can also inform on related modules:
- modules it depends on: `stock_picking_putinpack_restriction`
