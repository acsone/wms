=======================
Alc Sale Auto Subscribe
=======================

Alcyon: Auto subscribe specific user to sale order discussion


When a sale order is created, a specific 'CallCenter' user is automatically subscribed to the discussion of the sale order.
This user is a user without any access to the system, it is only used to receive the email notifications of the sale order discussion.
This ensures that the 'CallCenter' user is always aware of the sale order discussions and can take the necessary actions before being spam by email notifications for others models.
