====================================================
Alc Stock Receive Lot Missing Product Nouveaute Info
====================================================

Extends the Alcyon reception wizard by forcing the user to enter product infos
(weight, volume, ...) at the first reception of the product.

A setting (disabled by default) is there to enable/disable de constraints.

Config
======

* Go to *Invenory - Configuration - Settings - Products* and check the
'Reception Wizard Constraints' checkbox to enable the constraints.
