================================
Alc Stock Release Channel Unlock
================================

This module adds a wizard to simplify release channels unlock.
Usage
=====

1. Go to Inventory/Release channels/Unlock Release Channels
2. Select some tags
3. Click Unlock

The system will unlock  all release channels that have at least
one tag from the selected ones.
