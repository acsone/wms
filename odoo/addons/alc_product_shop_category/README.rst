==========================
Alc Product Web Categories
==========================

This module introduces a new product category named "Catalogue Alcyon" which is
designated as "web", along with all its subcategories.

Additionally, it creates a new menu item within the sales application that
allows users to access all categories, with a default filter applied to display
only the "web" ones.
