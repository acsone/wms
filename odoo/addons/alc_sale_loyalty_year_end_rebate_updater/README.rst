========================================
Alc Sale Loyalty year-end rebate Updater
========================================

Add a wizard to ease the update of loyalty rules for the year-end rebate program
with the managment of retroactive application of the new rules.

Purpose
=======

This module adds a wizard to ease the update of loyalty rules for the year-end rebate
program with the managment of retroactive application of the new rules. It proposes
different kind of update with the possibility to apply the new rules to the past
sale orders given a specific date.
