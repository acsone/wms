==========================================
Alc Stock Move Line Restrict Zero Quantity
==========================================

This module allows to trace and restrict stock move line quantity (reserved_uom_qty) change to zero or negative.

An error will be always logged in that case.

Configuration
=============

To configure this module, you need to:

#. Go to Inventory > Configuration > Settings > Operations > Restrict Move Line Quantity
#. Check the box if you want to restrict stock move line modifications on the 'reserved_uom_qty' field
