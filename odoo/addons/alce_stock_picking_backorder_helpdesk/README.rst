=====================================
ALCE STOCK PICKING BACKORDER HELPDESK
=====================================

Allows to create a helpdesk ticket upon backorder creation and the backorder
reason strategy adopted.

CONFIG
------

* Define backorder strategy and backorder reason on each desired operation
type
* Define helpdesk ticket strategy and helpdesk ticket reason on each desired
backorder reason
(*Inventory - Configuration - Warehouse Management - Backorder Reasons)
* The partner sale/purchase backorder strategy can be defined at company level
*Inventory - Configuration - Settings - Operations - Partner...Strategy*
