=========================
Alc Sale Product Narcotic
=========================

Add a warning to notify the user creating a sale order that a voucher is required to
buy narcotics

Configuration
=============

To configure this module, you need to:

#. Go to ...

Usage
=====

The warning is set on the product automatically when the product has one of the narcotic
or narcotic veterinary categories. On such a product, it is not possible to modify the
warning message.
