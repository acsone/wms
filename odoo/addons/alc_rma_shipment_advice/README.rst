=======================
Alc Rma Shipment Advice
=======================

This addon allows users to link RMA reception pickings to shipment advice,
enabling transporters to collect products for return when delivering to the customer.

When installed, the addon introduces a flag in picking types to identify RMA
operations. Upon validating a shipment advice, the system will search for RMA
receptions related to the customers in the shipment advice.

If applicable, these receptions will be linked to the shipment advice and can
be printed along with other deliveries.
Additionally, this addon extends the shipment advice report to indicate customers with returns.
