===========================
Specifc Helpdesk for Alcyon
===========================

This module improve the helpdesk module to manage the claims in Alcyon.


Helpdesk Ticket Reason
======================

New model allows to define reasons for the ticket.
A reason can be added on any ticket.


Reference
=========

New field Reference added to helpdesk ticket, allowing to select an objet and record:

* Partner
* Product
* Invoice
* Picking
* Lot/Serial number
* Repair

Add a link to define the linked sale/purchase order on the helpdesk ticket


Helpdesk ticket smartbuttons
============================

On following models, add smartbutton to access quickly to all linked helpdesk ticket:

* Partner
* Picking
* Sale order
* Purchase order
