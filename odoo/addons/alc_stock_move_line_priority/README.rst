============================
Alc Stock Move Line Priority
============================

Alcyon: Add priority field on stock.move.line

when you start managing the priority at the stock.move level, you need to be able
to manage it at the stock.move.line level in order to display the stock operations
in the right order.

This module adds a priority field on stock.move.line as related field of stock.move.
It doesn't change the default order of stock.move.line
