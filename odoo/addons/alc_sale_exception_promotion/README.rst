============================
Alc Sale Exception Promotion
============================

Adds the sale exceptions specific to promotional products.

Configuration
_____________

Please refer to alc_sale_exception README for the needed configuration.

Test
----

 * Go to *Sales - Configuration - Sale Exception Rules*
 * Activate the "warning_free_product" rule.
 * Create a product with promotional product
 * Crete a sale order with this product
