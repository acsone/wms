============================
Alc Sale Exception Promotion
============================

Adds the sale exceptions specific to promotional products.

Configuration
_____________

Please refer to sale_exception README to configure your user as
exception manager and be sure to be in developer mode to access the menu item
in *Settings - Technical - Exception Rules*.

Test
----

 * Activate the "warning_free_product" rule.
 * Create a product with promotional product
 * Crete a sale order with this product
