================================
Alc Sale Loyalty year-end rebate
================================

Add year-end rebate loyalty program

Purpose
=======

This modules defines adds year-end rebate loyalty program. 
The RFA program is a kind of fidelity program that allows customers to cumulate
points computed from the price sub-total of the sale order lines for specific
products.
Points earned by customers are calculated on the price sub-total (VAT excluded) of
the sale order lines.
A RFA loyalty program has a fixed reward of type year-end rebate which is not claimable.
