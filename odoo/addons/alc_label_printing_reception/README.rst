============================
alc label printing reception
============================

Add permission for reception user to change printer.

Also improve the standard lot reception wizard to allow printing a desired
number of labels.

Config
======

* Give your user the right 'RECEPTION - Change printer'
* Be sure at least one printer is defined *Settings - Printing - Printers*

Tests
=====

- Go to *Inventory - Products - Select Printing Printer* to select the label
printer
- Once in the reception wizard you'll find a Print button with a number at
the bottom left of the window
