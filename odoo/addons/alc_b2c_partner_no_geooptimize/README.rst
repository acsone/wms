==============================
Alc B2c Partner No Geooptimize
==============================

Enforce b2c partner to not be included in delivery based on geo-localization.


Usage
=====

Select "Client B2C" category in contact form. If "Delivery based on geo-localization"
checkbox is checked it will be unchecked automatically.
