==============================
Alc Sale Invoicing On Transfer
==============================

This module is based on partner_invoicing_mode_at_shipping OCA module which adds
a new invoicing method at shipping.

To activate this process set the shipping method of a customer to "At shipping"
and check "Create invoice on transfer" on the delivery picking type.
