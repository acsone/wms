=============================
Alc Stock Location Constraint
=============================

Allows to define a unique constraint on stock location based on its characteristics.

So, duplicate locations will be forbidden if they have same:

* Location Zone
* Corridor
* Rack
* Level
* Position (X and Y and Z)


Configuration
=============

To configure this module, you need to:

#. Go to Inventory > Configuration > Warehouse
#. Check the 'Storage Locations' box to activate the multi locations feature.
#. Check the 'Stock Location Constraint' if you want to activate that feature.
