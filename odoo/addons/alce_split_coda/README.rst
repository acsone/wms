Split CODA
==========

This module will split CODA by statement and pass it to the normal coda process in Odoo.

Installation
============

To install this module, you just need to select the module and insure yourself dependencies are available.

Configuration
=============

No configuration to use this module.


Known issues / Roadmap
======================

Doesn't support multiple rules for a same product or multiple locations
