===============
Delivery rounds
===============

Module to manage delivery rounds.
* Manage templates of delivery rounds
* Define a itinerary for delivery rounds (by template and by partner)
* Assign a delivery round on a picking
* Add a report for the driver with the delivery rounds
* Allow to define a delivery round on delivery carrier and use it at pricking creation


Installation
============

To install this module, you just need to select the module and insure yourself dependencies are available.

Configuration
=============

No configuration to use this module.
