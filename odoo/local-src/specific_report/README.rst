===============
Specific Report
===============

This module add some report for Alcyon:
- Delivery round
- Delivery slip
- Invoice (this report contains line to help to fold the paper)
- Purchase Order
- Passport report

The module will add a serial number on stock.move
This serial number is only used on the delivery slip.
