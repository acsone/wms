==========================================
Alcyon: Sale Product Expected Receipt Date
==========================================

This addon adds a new field on the sale order line 'next_expected_date_for_receipt'

This field displays the next expected receipt date for the products sold
(the receipt of the next purchase order)

This information is very useful for sale's people so that they can warn the
customer of the delay required to get an ordered product if it's out-of-stock.
