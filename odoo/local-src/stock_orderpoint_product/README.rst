Stock Orderpoint Product
========================

Display and manage the min/max from the product view.
Allows to import/export the min/max from the product and create/update the min/max rules.

Installation
============

To install this module, you just need to select the module and insure yourself dependencies are available.

Configuration
=============

No configuration to use this module.

Usage
=====

To use this module, you need to :
- open a product
- set the min/max in the procurement tab

Known issues / Roadmap
======================

Doesn't support multiple rules for a same product or multiple locations
